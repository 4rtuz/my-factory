# feature-sliced-design

Wrapper del submodulo `upstream` (https://github.com/feature-sliced/skills).

La skill vive en `upstream/feature-sliced-design`, fuera de la ruta `skills/` que
autodescubre Claude Code, asi que el `plugin.json` de esta carpeta la declara.

Actualizar: `git submodule update --remote tools/feature-sliced-design/upstream`
